# Diner menu system

### Problem statement
- There were many diners around the university campus at TalTech (ex TTÜ) in Tallinn Estonia. We, the students, were picky and wanted the best deals. So, we thought that we could create a solution to observe diner menus 

It was developed as a university subject project
